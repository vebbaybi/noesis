IMPLEMENTED HYBRID BRAIN LAYER
==============================

src/noesis_agent/brain/
- __init__                    # package exports for the NOESIS brain
- nlp_engine.py                  # local NLP: intent detection, keyword extraction, finance/web3 entity tagging, humor/risk signals
- adaptive_policy.py             # RL-inspired local policy learner with persisted reward updates
- finance_brain.py               # crypto/web3 reasoning with glossary grounding and risk framing
- humor_engine.py                # humor style control with safe boundaries for live rooms
- voice_profiles.py              # local voice profile store, sample ingest, and training-readiness tracking
- service.py                     # hybrid orchestration layer that combines local brain signals with API-backed generation

HYBRID ML / DL / RL / NLP STACK
===============================

- ML: local adaptive style scoring, hybrid retrieval scoring, finance/web3 heuristic reasoning
- DL: existing repo pipelines for Whisper, diarization, and OpenAI-backed generation/TTS
- RL: reward-updated style policy persisted under the local NOESIS store
- NLP: local intent classification, keyword extraction, risk detection, humor detection, and finance entity extraction
- Hybrid mode: NOESIS now builds local brain context first, then uses API generation when available, with a fully local fallback brain reply when APIs are offline
- Voice training base: NOESIS now supports voice profiles, sample ingest, pacing/humor preferences, and readiness checks for voice-training datasets
