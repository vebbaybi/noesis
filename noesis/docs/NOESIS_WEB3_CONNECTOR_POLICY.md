# Web3 Connector Policy

No new live connector was implemented in this phase. DefiLlama, CoinGecko, Snapshot, Farcaster, and GitHub require source-specific official endpoint verification, terms metadata, typed schemas, timeouts, bounded retry/jitter, rate limiting, circuit state, response limits, caching, freshness, attribution, and offline fixtures.

Market prices, TVL, proposals, and repository activity are retrieval facts, not training examples. When permission is unclear, sources must be retrieval-only with training disabled.
